# Electron 浅色控制栏设计

## 目标

在不改变摄像头主体、急停和现有快捷键的前提下，将 Electron 右侧数据栏改成不透明浅色界面，并增加可实际控制 Python 运行状态的手部识别开关和模式选择菜单。

## 界面

- Electron 模式下，Python HUD 使用不透明的浅蓝白背景、深色文字和蓝色状态色；原 OpenCV 窗口继续使用现有深色半透明 HUD。
- 右侧底部叠加两个原生 HTML 控件：
  - `手部识别`：按钮式 switch，默认开启，具备 `role="switch"` 与 `aria-checked`。
  - `控制模式`：原生 `select`，包含 `mirror`、`gesture`、`rps`。
- 急停按钮保持在控制区底部，红色含义和锁存行为不变。
- 控件使用白色表面、浅灰边框、蓝色 active/focus，所有点击目标不小于 44px。

## 行为

- 关闭识别后摄像头继续预览，但跳过 MediaPipe 识别、骨架绘制和动作映射。
- 关闭识别会让现有跟踪看门狗进入丢手流程，使灵巧手安全张开；不绕过急停与安全返回。
- 再次开启后恢复 MediaPipe 识别和跟随。
- 模式菜单发送明确模式，不通过多次模拟 `M` 键猜测当前状态。
- Python 在每一帧回传 `mode`、`detection_enabled`、`sending`，GUI 始终以 Python 实际状态为准；使用 `M` 或空格快捷键时控件也同步更新。

## 范围

- 保留 `Q`、`M`、空格、`E` 快捷键。
- 不增加设备配置、校准、日志或其他功能。
- 不改变上一轮张开端映射校正。

## 验证

- Python 测试覆盖命令解析、关闭识别时跳过识别器和安全返回、指定模式切换。
- Electron 测试覆盖白名单协议、帧状态解析、控件结构和响应式布局。
- 手动检查窗口缩放、键盘焦点、下拉菜单、识别开关和急停无重叠。
