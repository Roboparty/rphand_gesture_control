# RP-Hand 捏合、拇指与食指映射实验设计

## 目标

在不改变当前可用主分支的前提下，验证三项改进：

1. 扩大拇指和食指在连续映射模式下的有效行程。
2. 在拇指与食指靠近时提供连续、无突跳的捏合辅助。
3. 在 Electron 右侧控制区增加独立的“指令发送”开关，并与 `SENDING / PAUSED` 状态及空格键保持同步。

实验在 `experiment/pinch-thumb-index-mapping` 分支进行。急停和受控恢复逻辑保持不变。

## 已确认的真机证据

当前张开端已经按 2026-08-26 的样本校准，但闭合端仍统一假定为 `1.0`。

- 食指完全蜷缩时，校准后关节输出约为 `5579`。结合张开端 `0.2576`，对应校准前闭合输入约为 `0.672`。
- 拇指完全蜷缩时，校准后关节输出约为 `3021`。结合张开端 `0.2057`，对应校准前闭合输入约为 `0.446`。
- 捏合姿势能够被正确分类为 `pinch`，但画面中 `thumb_bend` 接近 `0`、`index_finger` 约为 `3836`，因此单纯的弯曲角映射无法让机械手形成有效捏合。

## 方案

### 逐指闭合端校准

沿用现有 `open / closed` 线性校准接口，只为拇指和食指增加实验闭合端：

- `thumb.closed = 0.446`
- `index.closed = 0.672`

其余通道保持现有配置。校准结果继续限制在 `[0, 1]`，因此超过样本闭合端的输入只会饱和，不会产生越界关节指令。

### 渐进式捏合辅助

识别器新增连续的 `pinch_strength`，由拇指尖与食指尖距离相对于掌长归一化得到。远离时为 `0`，接近接触时逐渐趋近 `1`。

连续映射先计算原始逐指目标，再按 `pinch_strength` 逐渐提高拇指弯曲和食指闭合目标；拇指旋转保留原连续映射与捏合辅助中的较强值。中指、无名指和小指不被捏合辅助覆盖。

捏合辅助参数放入配置文件并可关闭。关闭后行为应与仅增加闭合端校准的版本一致，便于真机 A/B 对比。

### 独立指令发送开关

Electron 控制区新增原生按钮实现的 switch：

- 开启表示 `SENDING`，允许视觉目标发送给驱动。
- 关闭表示 `PAUSED`，保持当前机械姿态。
- 点击开关和按空格键调用同一命令，并立即显示待确认状态；收到 Python 状态帧后完成同步。
- “手部识别”只控制识别与安全回张，不再承担暂停发送的界面含义。
- 后端处于 `STOPPED` 时禁用发送开关；受控恢复完成后，识别和发送仍分别保持关闭。

## 代码边界

- `gesture_recognizer.py`：只负责计算连续 `pinch_strength`。
- `gesture_mapping.py`：负责闭合端归一化与可配置捏合辅助，不接触驱动。
- `main.py`：把连续特征交给映射器，并继续维护 `sending` 状态。
- `electron/renderer`：展示和操作独立发送开关。
- `electron_bridge.py` 与 `electron/bridge-protocol.cjs`：继续复用现有 `toggle_pause` 命令，不增加重复协议。

## 安全约束

- 不修改 CAN-FD 连接、急停、恢复、回零、速度和电流配置。
- 自动测试不得加载真实 SDK、连接 CAN-FD 或移动真实灵巧手。
- 捏合辅助只能在连续映射模式生效，并始终经过现有关节范围映射。
- 真机首次验收先关闭发送观察数值，再在手指周围无障碍且可立即断电的条件下开启发送。

## 测试与验收

自动测试采用测试先行：

1. 拇指输入 `0.446` 映射到约 `10000`，食指输入 `0.672` 映射到约 `10000`；张开端仍映射到 `0`。
2. `pinch_strength` 随指尖距离缩短而单调增大，并限制在 `[0, 1]`。
3. 捏合辅助关闭时不改变原始输出；开启时只增强拇指、拇指旋转和食指通道，且连续变化。
4. Electron 页面存在独立发送 switch，点击与空格键均发送 `toggle_pause`，后端状态帧能够同步其开关状态。
5. Python 与 Electron 全量测试、PyInstaller 和 NSIS 打包全部通过。

真机验收顺序：

1. 保持发送关闭，依次观察张手、拇指完全蜷缩、食指完全蜷缩和捏合的显示值。
2. 开启发送，验证张手、握拳和其余三指效果没有回退。
3. 验证拇指和食指分别覆盖接近完整行程。
4. 缓慢靠近和分离拇指、食指，确认机械捏合连续且没有突跳。
5. 验证发送开关与空格键双向同步，再单独复核急停与恢复。

若捏合辅助导致误夹或影响普通动作，先通过配置关闭辅助；若闭合端校准造成过早饱和，则只调整对应通道的 `closed`，不改动其他手指。
